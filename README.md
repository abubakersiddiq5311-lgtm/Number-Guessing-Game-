Numbers Hunter Game 🎯
A fun and interactive CLI number guessing game built in Python. Test your luck and logic!

I built this as my first Python project while learning Data Science.

📖 About
The computer picks a secret number from 1 to 10 and you have 4 attempts to guess it. After each wrong guess, it gives you a smart hint to go Higher or Lower until you win or run out of tries.

✨ Features
🎯 4 Attempts - Limited tries for challenging gameplay
💡 Smart Hints - Tells you to go Higher or Lower
🔁 Replay Loop - Play again or exit when done
✅ Input Validation - Handles invalid numbers and choices
🚀 How to Run
Make sure you have Python 3 installed.
Clone or download this repository:
bash

git clone git clone https://github.com/abubakersiddiq5311-lgtm/number-hunter-game.git
3. Run the game: bash
python guessing_Game.py
```
